elvboot — elevated boot

elvboot is a FreeBSD verified-boot / tamper-detection project for a machine's own boot path. elebake, the tool this repository ships, compiles the boot trust chain: decisions live in a database, artifacts are generated, everything is inspectable and replayable.

  • elebake(8) — the manual page
  • Repository — README, design documents, the guided tutorial

Detection, not enforcement: the design assumes the boot medium can be tampered with and concentrates on noticing.
